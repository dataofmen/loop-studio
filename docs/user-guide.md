# 사용 가이드

Loop Studio는 설문을 **설계하고 · 검토하고 · 미리 보고 · 합성 응답으로 시뮬레이션**합니다.
응답 수집은 하지 않습니다 — 문항이 실제로 어떻게 작동할지 사람에게 배포하기 전에 확인하는
도구입니다.

## 준비

AI CLI 하나를 설치하고 로그인해 두세요. 설계·검토·시뮬레이션이 전부 이 CLI를 통해 실행됩니다.

```bash
npm i -g @anthropic-ai/claude-code     # 또는
curl https://cursor.com/install -fsS | bash
```

CLI가 잡히지 않으면 대시보드 상단에 안내가 뜹니다. **설정**에서 도구를 바꾸거나 실행 파일
경로를 직접 지정할 수 있습니다.

## ① 설계

**대시보드 → 리서치 목표 입력 → AI로 설문 생성.** 목표는 구체적일수록 좋습니다. 목적이 둘
이상이면 나눠서 적어 주세요 — 문항이 목적별로 묶여 나옵니다.

생성에는 1~2분 걸립니다. 결과는 초안이며, **① 설계** 탭에서 손댈 수 있습니다.

- **문항 편집** — 유형(단일·복수·척도·NPS·순위·행렬·주관식), 보기, 환영/종료 문구
- **표시 로직** — 앞 문항의 답에 따라 이 문항을 보일지 결정
- **보기 이어받기(carry-forward)** — 앞 문항에서 고른 보기만 이 문항의 보기로
- **데모그래픽 프리셋** — 성별·연령대·지역·직업·학력·혼인·가구소득 표준 문항을 한 번에 추가
- **AI 수정 제안** — 피드백을 적으면 수정안을 만들어 전/후로 비교해 보여줍니다. 적용하면
  버전이 기록되고 언제든 과거 버전으로 되돌릴 수 있습니다.

> 수정안 적용은 문항 행을 교체합니다(ID 변경). 시뮬레이션을 돌린 뒤에 적용하면 기존 합성
> 응답과 문항이 어긋나므로, 설계를 먼저 마무리하는 편이 낫습니다.

## ② 검토

**개요** 탭의 **AI 검토 실행**은 두 층으로 점검합니다.

1. **구조·로직 검사**(즉시) — 도달 불가 문항, 모순된 표시 조건, 보기 문제
2. **AI 종합 검토**(2~5분) — 유도 질문, 이중 질문(double-barreled), 보기 누락, 목표와의 정합성

이슈마다 **수정안 생성**을 누르면 설계 탭에서 그 이슈를 반영한 수정안이 바로 만들어집니다.
여러 이슈를 골라 한 번에 보낼 수도 있습니다.

검토가 깨끗하면 **검토 완료로 표시**가 가능합니다. 강제성은 없습니다 — 경고를 확인하고
넘어갈 수 있습니다.

## ③ 미리보기

**미리보기 열기**는 응답자가 보는 화면 그대로를 보여줍니다. 표시 로직·보기 이어받기·보기
섞기·기타 입력이 실제로 동작하므로, **로직의 모든 분기를 직접 밟아 보세요.** 아무것도
저장되지 않으며, 종료 화면에서 **처음부터 다시 보기**로 다른 경로를 시도할 수 있습니다.

## ④ 시뮬레이션

**페르소나 표본**을 먼저 만듭니다.

- 기본값은 AI가 설명("20~40대 배달앱 이용자")에 맞는 페르소나를 생성하는 방식입니다.
  그럴듯하지만 **실제 인구 분포를 따르지는 않습니다.**
- 공식 인구통계에 비례하는 **대표성 표본**은 페르소나 코퍼스가 설치돼 있어야 합니다
  (README의 "페르소나 코퍼스" 참고).

그다음 **시뮬레이션 실행**. 페르소나마다 설문에 답하고, 표시 로직과 보기 이어받기는 실제
제출과 같은 규칙으로 처리됩니다.

속도와 품질의 트레이드오프가 있습니다 — **설정**에서 조절하세요.

| 설정 | 의미 |
|---|---|
| 호출당 페르소나 수 | 크면 빠르고 저렴하지만 한 응답이 다른 응답을 닮아갈 수 있습니다. **1이면 완전히 독립** |
| 동시 실행 수 | 동시에 띄우는 CLI 프로세스 수 |

일부 페르소나가 실패하면 완료 처리하되 경고를 남깁니다 — "전원 성공"으로 위장하지 않습니다.

## ⑤ 결과

- **응답 분포** — 문항별 분포. 척도는 긍정률, NPS는 점수, 순위는 평균 순위. n이 30 미만이면
  '표본 작음' 배지가 붙습니다.
- **AI 인사이트** — 핵심 발견과 권장 액션
- **주관식 테마** — 주관식 응답을 주제별로 묶고, 각 테마는 근거 응답으로 역추적됩니다
- **리포트** — 발견·테마·주의사항을 담은 스냅샷. 마크다운으로 내보낼 수 있습니다
- **내보내기** — 분석용 CSV(wide/long), AI 번들(zip), SPSS 번들(zip)

> 모든 결과는 **합성 데이터**입니다. 실제 응답이 아니며, 산출물마다 그렇게 표기됩니다.
> 사람의 의견을 대체하는 근거로 쓰지 마세요 — 문항이 잘 작동하는지 확인하는 용도입니다.

## 데이터와 프라이버시

- 모든 데이터는 내 컴퓨터의 폴더 하나에 있습니다. **설정 → 폴더 열기**로 확인할 수 있고,
  백업은 폴더 복사, 초기화는 삭제입니다.
- 서버는 `127.0.0.1`에만 바인딩되어 같은 컴퓨터에서만 접근됩니다. 로그인이 없는 이유입니다.
- **설문 내용은 내가 로그인한 AI 제공자로 전송됩니다** — 설계·검토·시뮬레이션이 그 CLI를
  호출하기 때문입니다. 민감한 내용을 다룰 때는 해당 제공자의 데이터 정책을 확인하세요.
- 텔레메트리·사용 분석·외부 전송은 없습니다.

## 재사용

- **템플릿** — 설문 전체 / 문항 블록 / 단일 문항 단위로 저장해 다른 설문에 삽입
- **구성 개념(construct)** — 같은 개념을 측정하는 문항이 설문 간에 이어지도록 통제 어휘로
  정규화합니다. 개념을 지정해 두면 다음 설문 생성 시 검증된 문항 표현을 재사용합니다.
